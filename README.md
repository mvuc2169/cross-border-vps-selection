## 下单前要问清楚的五个问题

这五个问题适用于任何年缴型 VPS，两个 SixNet 已经在页面上回答了，剩下三个得自己确认。

**1. 80 和 443 端口开不开？** SixNet 已经答了：Residential 和 IRVINE-PRO 不开。所以建站只能选 LAX 或 LAX-Storage。

**2. 25 端口能不能出站？** 这条最容易被忽略，但直接决定订单通知邮件能不能发出去。腾讯云国际版轻量的做法是 TCP 25 出站端口默认封禁且不支持解封，SMTP 只能用 465 或 587 端口，必须接第三方邮件服务。SixNet 的页面对此没有说明，装好 WooCommerce 第一件事就是测一封订单邮件，发不出去就立刻配 SMTP 插件走 465/587。

**3. IP 被墙或拉黑之后怎么办？** 腾讯云轻量的公网 IP 在实例生命周期内只能自助更换 1 次，IP 一旦被拉黑无法恢复，只能重建实例。SixNet 的换 IP 政策页面未标注，买之前问清楚次数和是否收费。

**4. 快照算不算备份？** 不算。磁盘快照的用途是版本回滚，实例释放时快照会一并删除。正确做法是快照 + WordPress 插件定时导出数据库到外部存储，两套并行。SixNet 的页面上没有提到快照服务，那数据库备份就必须自己配好。

**5. 防火墙有几层？** 控制台的安全组是外层过滤，操作系统里的 iptables 或 firewalld 是第二层，两者串联，谁也替代不了谁。KVM 机型系统防火墙要自己配，只放行 80、443、SSH 端口，MySQL 的 3306 绝不能对公网开放。

## 国内团队要登后台，值不值得为线路加钱

买家打开前台和运营团队登后台，走的是两段完全不同的链路，后一段经常被忽略。外贸站长每天要传产品图、改价格、查订单，如果服务器对国内访问没有任何优化，光上传一张图就要等半天。

SixNet 里对应「中国方向优化」的是 IRVINE-PRO 系列，配置栏标了 AS9929 Optimize for China，走的是联通精品网。但它同时是住宅 IP、不开 80/443、默认拒绝外部探测，所以它解决的是「从国内连这台机器快不快」，不是「买家用浏览器能不能打开你的站」。

判断规则可以简化成两条：

- 买家全在欧美，国内团队一周登两三次后台 → 不必为中国方向线路付溢价，LAX 系列够用。多付的钱买的是你自己的操作手感，不是买家的加载速度。
- 国内团队每天都要进后台改东西 → 线路溢价是值得的，但要先确认这台机器能不能挂站。在 SixNet 的产品线里，这两个需求目前不在同一个套餐上。
